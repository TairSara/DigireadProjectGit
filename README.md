# DigireadProjectGit

## Introduction
DigiRead is an innovative project providing digital access to books, enabling readers to purchase or borrow books online. The site was developed as a student project at SCE - Shamoon College of Engineering in Beer Sheva, aimed at making literature digitally accessible.

## System Capabilities
* Digital purchase and lending of books
* Reading history tracking
* Waitlist management
* Rating and recommendation system
* Support for multiple formats (F2B, PDF, EPUB, MOBI)

## Special Feature - Remembering the Hostages
As part of our social commitment, we have integrated a special timer displaying the time elapsed since Israeli citizens were kidnapped by Hamas. This element was added as an expression of solidarity and hope for their swift and safe return home.

## Technologies Used
The system was developed using the following technologies:
* SQL Server - Database
* Azure - Cloud infrastructure
* Visual Studio - Development environment
* Rider - Additional development environment

## Key Features
### User Management
* User registration and authentication
* Personal library management
* Reading history tracking
* Wishlist functionality

### Book Management
* Digital book catalog
* Multiple format support
* Rating and review system
* Waitlist functionality

### Purchase and Rental System
* Shopping cart
* Secure payment processing
* Digital book delivery
* Rental period management

## Project Structure
* Frontend: HTML, CSS, JavaScript, jQuery

* Database: SQL Server
* Cloud Services: Azure
